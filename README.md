# Python Core — Capstone Projects

A collection of three projects designed to consolidate Python fundamentals through practical application.

The goal is to cover the core Python concepts by building real applications rather than completing isolated exercises.

## Projects

### 1. Student Performance Analyzer
**Focus:** Data processing and analysis.

- CSV file handling
- Data structures and comprehensions
- Functions and modular programming
- Filtering, sorting, and aggregation
- Error handling and data validation
- JSON and CSV export
- Unit testing

### 2. Personal Finance Tracker
**Focus:** Object-oriented programming and application design.

- Classes and objects
- Encapsulation and methods
- Type hints and clean interfaces
- Dates, numbers, and financial calculations
- File persistence
- Input validation and exceptions
- Unit testing

### 3. Dataset Analyzer
**Focus:** Algorithms, reusable code, and data processing.

- Iterators and generators
- Functional tools and comprehensions
- Algorithms and complexity fundamentals
- Reusable modules and packages
- Advanced file handling
- Sorting, searching, and aggregation
- Testing edge cases

## Learning Goals

By completing all three projects, the goal is to consolidate:

- Python syntax and control flow
- Built-in data types and data structures
- Functions, scope, and argument handling
- Comprehensions, iterators, and generators
- Modules, packages, and imports
- Object-oriented programming
- Exceptions and validation
- File handling and serialization
- Type hints and code organization
- Testing and debugging
- Basic algorithms and complexity
- Virtual environments and dependency management
- Git and project documentation

## Tech Stack

- Python 3
- Python standard library
- Git and GitHub
- `unittest`

Each project has its own README describing its functionality, implementation, and learning objectives.
