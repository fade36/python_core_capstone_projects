
# Student Performance Analyzer

A command-line Python application for analyzing student academic performance using a real-world dataset.

The first of three Python Core capstone projects, focused on data processing, analysis, and file handling.

## Dataset

[UCI Student Performance](https://archive.ics.uci.edu/dataset/320/student+performance)

only student-mat.csv

- 395 student records
- 33 original attributes

## Features

- Load and validate CSV data
- Filter, sort, and analyze student records
- Compare academic performance
- Export results to JSON and CSV
- Test functionality with automated unit tests

## Python Core Topics

- Data structures and comprehensions
- Functions and modular programming
- File handling and serialization
- Error handling and validation
- Data filtering and aggregation
- Unit testing
